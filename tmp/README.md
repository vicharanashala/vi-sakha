# 📁 Ephemeral Debug & Manual Triage (`/tmp`)

This directory is an ephemeral workspace housing manual verification scripts, database validation code, and active session debug configurations.

> [!WARNING]
> Do **not** store persistent code or configurations in this directory. Content in this directory is strictly for local verification purposes.

---

## 🔗 Utilities Inside

*   `check_db.js` — Quick node script to inspect database connections, collections sizing, and indices validation.
*   `debug_firebase.js` — Script to execute mock Firebase tokens generation and header checks.
