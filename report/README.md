# 📊 Academic Reports & Compliance Specs (`/report`)

This directory houses official **VInternship academic milestone reports**, system specifications, user story maps, and Swagger enrichment prompts. It is used to trace compliance with project requirements.

---

## 🔗 Contents

*   `Milestone - 1 Team 77.pdf` / `Milestone - 3 Team77.pdf` — Comprehensive academic milestone writeups explaining architectures, user stories, and databases.
*   `API_UserStory_Mapping.txt` — Maps individual REST and Socket.io endpoints directly to User Story (US) requirement bounds (e.g. Student interactive consults, Admin role rules).
*   `swagger_enrichment_prompt.md` — The exact LLM prompts used to enrich the Swagger/OpenAPI spec contract (`swagger.yaml`).
*   `errors.txt` — Log archives containing test failures and trace logs for reference.
